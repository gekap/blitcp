Install on Windows

blitcp copies folders to another drive, a NAS, another machine or cloud storage — and verifies every file arrived. On Windows it is a standalone .exe: no installer, no Python, no administrator rights. Pick one below and double-click it.

Step 1 — which one do you need?

Most people

blitcp_gui-windows.exe — the app

A normal window. Browse for a folder, pick where it goes, watch it run. Handles local drives, SSH, SMB and cloud from the same screen.

Download the appv4.2.10 · 85 MB · Windows 10/11 · 64-bit
Terminal & scripts

blitcp-windows.exe — the CLI

One command, documented exit codes, --progress for anything that needs to parse the output. What you want in a scheduled task.

Download the CLIv4.2.10 · 46 MB · Windows 10/11 · 64-bit

Both are built from the same release commit and published only on GitHub Releases. Already have Python? pip install blitcp works too.

Step 2 — the warning you are about to see

“Windows protected your PC” is expected here

Microsoft Defender SmartScreen shows this blue dialog for any program that is not code-signed with a paid certificate and has not yet built download “reputation”. It is a statement about popularity and signatures, not about what the program does. blitcp is not signed because code-signing certificates cost several hundred euros per year — hard to justify for a free, open-source tool — though funding could change that — whose every line of source is public and whose binaries are built from that source with PyInstaller.

To proceed past the dialog:

  1. Click More info (small link under the text).
  2. Click Run anyway.

This is needed once per downloaded file. But don't take the dialog's word — or ours — for it: verify the file cryptographically instead. It takes ten seconds.

Getting rid of this warning for everyone is the single most useful thing donations buy. How to help →

Step 3 — verify your download (optional)

Check the SHA-256

In PowerShell, in your Downloads folder:

Get-FileHash .\blitcp-windows.exe -Algorithm SHA256

Compare the output against the official digest below. These hashes are computed by GitHub itself when each binary is uploaded to the release — the same values are shown via the GitHub API for the release. If the hash matches, the file on your disk is byte-for-byte the file from the release; if it doesn't, delete it and re-download from GitHub only.

Antivirus false positives

PyInstaller-packaged Python programs are occasionally flagged by antivirus heuristics simply because of how they bundle the interpreter — it is a known false-positive pattern that affects many open-source Python tools. If your AV quarantines a file whose SHA-256 matches the official digest above, the file is exactly what was released; you can inspect the source it was built from or build it yourself with build.py.

Step 4 — your first copy

One minute from here

  1. Open the app — double-click blitcp_gui-windows.exe. There is nothing to install and nothing to sign into.
  2. Pick source and destination — a local folder, an external drive, an SSH host or a cloud bucket. blitcp shows the plan before it writes anything.
  3. Press Start — verification runs by default. When it finishes green, every file has been read back and compared.

Or, from the command line

.\blitcp-windows.exe "C:\Projects\my-app" "E:\Backup\my-app"

That's it — no installation step. See the local copies guide for more examples (long paths, ReFS block cloning and NTFS hardlink dedup are handled automatically), or the full CLI reference.
